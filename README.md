# LACIMA Tools

Small plug-ins for Photoshop, Illustrator, After Effects and music production, made by an indie developer in Italy.

| Plug-in | What it does |
|---|---|
| [NineSlicer](https://lacimatools.com/nineslicer) | 9-slice scaling inside Photoshop: resize UI frames and panels without stretching the corners |
| [SpriteExporter](https://lacimatools.com/spriteexporter) | Export Photoshop layers and groups as PNG at full canvas size, untrimmed |
| [SpriteSheet](https://lacimatools.com/spritesheet) (free) | Layers to sprite sheet and sprite sheet back to layers, frames kept in place |
| [PixelDrop](https://lacimatools.com/pixeldrop) (free) | Import pixel art into Photoshop at its original size, without blur |
| [DitherFactory](https://lacimatools.com/ditherfactory) | 27 dithering algorithms as one After Effects effect |
| [VectorBridge](https://lacimatools.com/vectorbridge) | Illustrator paths to editable After Effects shape layers, and back |
| [CS-01](https://lacimatools.com/dsp/cs-01) | Synth plug-in (VST3, AU, standalone) modelled on the Yamaha CS01 and CS01 II |
